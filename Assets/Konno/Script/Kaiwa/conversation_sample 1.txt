// 会話スクリプトのサンプル
// Database に yonesima（表情: normal, smile, trouble）と kanade（normal）、
// 背景 classroom を登録しておく

@bg classroom 0
@fade in 1.0

: ある日の出来事…

@show yonesima normal center
yonesima: お前、ﾀﾋね！
@jump yonesima
yonesima(smile): うざいんだよ

@show yonesima left
@show kanade normal right
@wait 0.3
kanade:お前もﾀﾋね！
@emote yonesima !?
yonesima(trouble): ！？
  ほんのちょっと、手伝ってほしいだけで……
@shake kanade
kanade: その「ちょっと」が一番信用できないんだけど。

@choice
- ころす -> help
- けす -> depends

*help
@face yonesima smile
yonesima: ほんとですか！？ ありがとうございます！
@jump yonesima 2
@goto finish

*depends
kanade: ……賢明な判断ね。
@emote yonesima …
yonesima(trouble): うう、まずは話だけでも聞いてください〜

*finish
@fade out 1.0
@end
